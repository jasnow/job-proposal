# Job Post: GHSA Ruby Data Advocate

This job would focus on improving the GHSA[1] Ruby-based data/process.
 * Definition
   * Ruby Gems[2] and Ruby language[0] security advisories
   * Sit between GitHub repo security advisories]3] and
     global GHSA security advisories[1].
     * Handle "unreviewed"[4] ruby-based security advisories.
     * Continue to create ruby-advisory-db[5] security advisories using
       current process (I create PR, another person reviews, I merge).
       * Work ruby-advisory-db/lib/rad-ignores.sh security advisories.
     * Handle advisory-database[6] repo's ruby-based PR triage.
   * Based Remotely (travel to GitHub site for training).
   * Paid position
     * Salary plus some benefits
     * Equipment expenses
   * Tools and infrastructure to support this work.
   * (TBD) If ruby/rails conferences are included.
     * Workshop (How to created ruby-advisory-db advisories)
     * Travel/expenses
